# Code of Conduct

## Our standards

We build an open, professional technical community. Participants are expected to:

- Communicate with technical accuracy and factual evidence
- Accept feedback on code and design without taking it personally
- Respect that maintainers make final decisions on project direction
- Keep discussions focused on the work

The following are not welcome:

- Harassment, insults, or personal attacks in any form
- Discrimination based on personal characteristics unrelated to technical contributions
- Publishing private information (real names, addresses, contact details) without consent
- Sustained disruptive behavior in issues, PRs, or other community spaces

## Scope

This code of conduct applies to all project spaces: GitHub issues, pull requests, discussions, and any other venue where someone represents the project.

## Enforcement

Violations can be reported to the maintainer via the channels listed in [SECURITY.md](SECURITY.md) (use the Telegram contact for conduct issues).

The maintainer will:

1. Review the report within 5 business days
2. Determine whether a violation occurred
3. Apply a proportionate response: a warning, temporary ban, or permanent ban depending on severity

All reports are kept confidential.
