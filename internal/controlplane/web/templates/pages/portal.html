Happ Proxy Utility

Fast, battery-efficient client supporting VLESS Reality and AmneziaWG.

Connect in Happ (1-Click) → App Store
Quick Steps:
1. Install Happ from the App Store.
2. Tap "Connect in Happ (1-Click)" above.
3. Allow VPN profile when prompted and toggle switch to Connected.

Recommended Client: v2rayNG
v2rayNG for Android

Reliable open-source client with automatic profile synchronization.

Connect in v2rayNG (1-Click) → Google Play
Quick Steps:
1. Install v2rayNG from Google Play or GitHub.
2. Tap "Connect in v2rayNG (1-Click)" to load your subscription.
3. Tap the round V icon in the lower right corner to connect.
Alternative: Sing-box 1-Click Import
Recommended Client: Clash Verge Rev / Hiddify
Clash Verge Rev

Modern Windows client with System Proxy and TUN mode routing.

Connect in Clash Verge (1-Click) → GitHub
Quick Steps:
1. Download and install Clash Verge Rev.
2. Tap "Connect in Clash Verge (1-Click)" to import the profile.
3. In the client, enable System Proxy and select your edge node.
Recommended Client: Streisand / Happ
Streisand for macOS

Native macOS application with seamless system integration.

Connect in Streisand (1-Click) → Mac App Store
Quick Steps:
1. Install Streisand from Mac App Store.
2. Tap "Connect in Streisand (1-Click)" to add profile.
3. Select node and switch Connection to Connected.
Recommended Client: Sing-box / Hiddify
Sing-box for Linux

Universal proxy engine supporting TUN mode and headless operation.

Connect in Sing-box (1-Click) → GitHub
Quick Steps:
1. Download sing-box or Hiddify from GitHub.
2. Tap "Connect in Sing-box (1-Click)" or download sing-box.json below.
3. Run sing-box daemon or start Hiddify GUI.
