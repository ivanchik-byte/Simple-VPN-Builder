White-Label Partner Integration Guide

How to Create and Configure a Partner Telegram Bot

Each partner can launch an independent bot that operates under their unique brand identity. Users who register through this bot belong to the partner's tenant database.

Open @BotFather
01 Register the Bot via @BotFather
  1. Message @BotFather and send: /newbot
  2. Enter a public Brand Display Name (e.g. "Alpha VPN").
  3. Choose a username ending in bot (e.g. "AlphaVpnService_bot").
  4. BotFather will return your secret HTTP API Token.
Token sample: 7123456789:AAHk...
02 Required Botfather Settings
1. Disable Privacy Mode

Send /setprivacy -> Select bot -> Choose Disable so bot handles all callbacks.

2. Set Menu Commands

Send /setcommands -> Paste: start, trial, status, help.

3. Set Bot Description & Avatar

Send /setuserpic to upload brand logo and /setdescription for greeting screen.

Automatic Webhook Routing AUTO-REGISTERED

When you add the partner bot in this panel, Simple-VPN-Builder automatically generates the isolated webhook endpoint /api/v1/webhook/telegram/{tenant_id}. Inbound updates from your bot's users are partitioned into the partner's database slice.

Creating a Telegram Mini App (TWA) for the Partner Bot

Telegram Mini Apps provide an integrated in-chat web app experience. Subscribers can manage their VPN servers, renew subscriptions, and download WireGuard/Xray profiles directly inside Telegram.

Method A: Dedicated Mini App (/newapp)
  1. In @BotFather, run /newapp.
  2. Select your partner bot from the list.
  3. Enter the Mini App Title (e.g. Alpha VPN Portal).
  4. Enter Short Description (e.g. Instant VPN configuration and traffic stats).
  5. Upload an App Banner photo (recommended: 640x360 px).
  6. Enter the Web App URL:
    https://YOUR_DOMAIN/client/
  7. Choose a short name (e.g. app). Your direct TWA URL becomes: https://t.me/YourBot/app
Method B: Chat Menu Button (/setmenubutton)

Adds a persistent native button in the bottom left of the chat window for all users (replacing the generic "/" command button).

  1. Send /setmenubutton to @BotFather.
  2. Choose your partner bot.
  3. Select "Configure menu button".
  4. Enter Menu Button Title: Launch VPN App
  5. Enter URL: https://YOUR_DOMAIN/client/
Users can launch the full graphical client portal without ever leaving Telegram on iOS, Android, macOS, and Desktop!

Connecting a Custom Website / Branded Domain

Provide white-label partners with their own portal URL (e.g. vpn.partnerbrand.com) for client subscriptions, guides, and landing pages.

01 DNS A / CNAME Record

In your domain registrar (Cloudflare, Namecheap, Route53), add a DNS record:

Type: A
Host: vpn (or @ for apex)
Target IP: YOUR_SERVER_PUBLIC_IP
02 Caddy / Nginx Reverse Proxy

Simple-VPN-Builder Caddyfile configuration with zero-touch Let's Encrypt SSL:

vpn.partnerbrand.com {
    reverse_proxy localhost:8110
}
Client Subscription Route:
https://vpn.partnerbrand.com/sub/{token}

Zero-Knowledge Multi-Tenant Architecture

How Simple-VPN-Builder guarantees subscriber isolation, referral revenue partitioning, and secure node encapsulation.

Data Partitioning
Tenant Tagged Users

Users who interact with a partner bot receive a foreign key tenant_id. Their billing transactions and activity records remain partitioned.

Node Shielding
Encapsulated Keys

Partner administrators never have direct SSH access or raw WireGuard/Xray server keys. The Control Plane handles key generation and peer updates via mTLS.

High Availability
Parallel Webhook Pool

Each partner webhook runs concurrently without blocking the main engine. Update bursts on one partner bot do not impact other partners.
